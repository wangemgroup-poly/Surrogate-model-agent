# 变更记录

日期为在真实 CST 工程（4、6、8、10、12 缝波导缝隙阵）上验证该行为的时间。

## 0.3.0

### 新增
- **多工程导入。** `import-cst --project A.cst --project B.cst` 可合并同一结构多个版本的已保存结果，
  非源工程的样本 ID 会加版本前缀。老版本工程里常常存着比最新文件更好的设计，不把它们纳入训练，
  替代模型就是在一个盲区里做优化。
- **`bounds` 命令**——写配置前打印各工程的优化器范围及其并集。
- **导入时的范围提示**——当所导入工程的优化器范围**或已保存样本本身的参数取值**超出任务范围时，
  写 `bounds_advice.json` 并记事件。工程的优化器范围常在跑完一轮后被收窄，这会让早期的好样本
  在导入时被静默拒绝。
- **`import_summary.json`**——按工程记录读入/入库/重复/拒绝/无结果的数量。
- **候选预警**——每个冻结候选记录它到最近样本的距离相对数据最近邻中位距离的倍数
  （`extrapolation_ratio`），以及其他算法对同一设计的交叉核查分歧（`disagreement_limit`）。
- **`optimize` 的保守约束**——"预测最优"候选按 μ + `conservative_sigma`·σ 判断约束，不再只看均值。
- **报告新增**——约束取舍表、约束两两之间的余量相关性、无第三方依赖的 `tradeoff.svg` 散点图、
  参数触边统计、收敛概况；候选表增加预警列。
- **`materialize` 命令与规则**——把已验证的设计写回源工程求解保存，便于在 CST 里查看曲线；
  操作前完整备份，并保留工程原有的求解器设置。`run` 闭环中库内最优被刷新时自动执行
  （`materialize.on`：`improvement`/`pass`/`never`；`materialize.max` 限制单次调用的次数）。
- **`rebaseline` 命令**——源工程仅新增了保存的 Run 时重新登记。
- **非 ASCII 路径自动建目录联接**——CST 的结果库打不开这类路径，此前每个任务都要写一份绕行脚本。
- **备份复制支持扩展长度路径**，CST 结果树再深也不会撞上 Windows 260 字符上限。

### 变更
- **源工程的身份是"结构"而不是"文件"。** 任务登记几何签名（`Model.mod`、`ModelHistory.json`、
  求解属性）**以及任务未优化的全部固定参数取值**。往源工程里保存新的 Run 不再使任务失效；
  改固定尺寸或几何仍然会。仅凭几何历史相同并不够：两个版本可以用同样的建模历史配不同的固定尺寸，
  因为那些取值存在 `Parameters.json` 里。
- **配置签名不含执行类设置。** 改 `simulation_budget`、`cpus`、`timeout_minutes` 或登记的哈希，
  不再作废已训练模型与已冻结批次；改目标、参数范围或挑点方法仍会。

### 修复
- 结果树很深的工程在备份复制时报 `WinError 206`。
- 范围提示漏掉了"样本本身越界（而非优化器设置越界）"的情形。

## 0.2.0

### 新增
- **`proposal_method: "optimize"`**——直接在替代模型上做差分进化，`search_domain` 可取
  `trust_region` 或 `full`，并约束候选与已有样本的最小距离、候选之间的最小间隔。
  局部 GP 只拟合当前中心附近 120 点，因此禁止用它做全域搜索。
- **`proposal_method: "sb_sadea"`**——Liu et al.（IEEE TAP 2022）的在线闭环：λ 个最优设计组成种群、
  DE/current-to-best/1、每个子代用最近 τ 个样本训练局部代理、自适应 LCB，每轮只做 1 次全波仿真。
- **罚函数适应度**，各指标 `penalty_weight` 可配置——当搜索反复拿一项指标换另一项时，这是引导手段。
- **变分推断 BNN**（`sb_sadea.surrogate: "bnn"`，PyTorch，多子代 GPU 并行），并暴露 `kl_weight`，
  因为论文没有说明 KL 项如何缩放；按字面取值时，小样本下网络会退化成近邻均值。
- **可选的全样本 GP**（`include_global_gp`），适用于规模在限制内的任务。

### 变更
- SB-SADEA 的默认局部代理改为 ARD-Matérn GP（ω=2），即论文表 III 的 GP-ALCB 变体。
  在一个 13 参数的实测检验中，它的精度约为论文 BNN 的两倍，耗时相当。
